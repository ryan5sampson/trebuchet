# The Trebuchet

A scroll-through, blueprint-themed field guide to trebuchets for the classroom:
what they are, their history, trebuchet vs. catapult, types, parts, physics, a
launch simulator, how to build one, and what replaced them.

It's one static page, `index.html`. Open it in a browser, or serve it with
GitHub Pages.

Photos come from Wikimedia Commons; each caption links to its file page for the
author and license. Videos are embedded from YouTube.
